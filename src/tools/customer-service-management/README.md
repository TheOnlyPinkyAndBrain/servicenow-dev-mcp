# Customer Service Management (CSM)

Cases, accounts, contacts, and case tasks.

**Module folder:** `src/tools/customer-service-management/` · **Files:** 1 · **Tools:** 6

Read-only tools (`both`) work in `debug` and `develop` modes; `develop` tools require `SERVICENOW_MODE=develop`.

| Tool | Mode | Description |
|------|------|-------------|
| `sn_csm_account_list` | both | List customer accounts |
| `sn_csm_case_create` | develop | Create a CSM case using the Customer Service API |
| `sn_csm_case_get` | both | Get full CSM case details including tasks and communications |
| `sn_csm_case_list` | both | List Customer Service Management cases (sn_customerservice_case) |
| `sn_csm_case_update` | develop | Update a CSM case |
| `sn_csm_contact_list` | both | List customer contacts |
